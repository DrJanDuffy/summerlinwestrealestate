# SEO Audit Command

Perform a comprehensive SEO audit for real estate pages.

## Usage
/seo-audit [page-url]

## What it does
- Analyzes page titles (50-60 characters)
- Checks meta descriptions (150-160 characters)
- Validates image alt text
- Reviews Core Web Vitals
- Checks mobile responsiveness
- Verifies structured data implementation
- Analyzes keyword density and placement

## Real Estate Focus
- Ensures location keywords (Summerlin West, Las Vegas)
- Validates property-specific SEO elements
- Checks for fair housing compliance
- Reviews lead generation optimization

## Output
- Detailed SEO report with actionable recommendations
- Priority fixes for immediate impact
- Long-term optimization suggestions
