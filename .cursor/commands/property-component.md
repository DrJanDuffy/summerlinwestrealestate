# Property Component Generator

Generate optimized property listing components for real estate websites.

## Usage
/property-component [property-type] [features]

## What it does
- Creates responsive property cards
- Implements proper TypeScript interfaces
- Adds SEO-optimized metadata
- Includes accessibility features
- Optimizes for Core Web Vitals
- Integrates with RealScout API

## Real Estate Features
- Property image galleries
- Price formatting and display
- Location and neighborhood info
- Contact forms and lead capture
- Market data integration
- Mobile-first responsive design

## Output
- Complete React component with TypeScript
- CSS modules with BEM methodology
- SEO metadata and structured data
- Accessibility compliance (WCAG)
- Performance optimizations
