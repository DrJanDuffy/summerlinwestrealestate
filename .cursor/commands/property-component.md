# V0.app Property Component Generator

Generate optimized property listing components using V0.app for real estate websites.

## Usage
/v0-property-component [property-type] [features]

## What it does
- **V0.app FIRST**: Uses V0.app to generate property components
- Creates responsive property cards with V0.app
- Implements proper TypeScript interfaces via V0
- Adds SEO-optimized metadata through V0 generation
- Includes accessibility features via V0.app
- Optimizes for Core Web Vitals with V0
- Integrates with RealScout API

## Real Estate Features
- Property image galleries generated by V0.app
- Price formatting and display
- Location and neighborhood info
- Contact forms and lead capture
- Market data integration
- Mobile-first responsive design

## Output
- Complete React component with TypeScript (V0.app generated)
- CSS modules with BEM methodology
- SEO metadata and structured data
- Accessibility compliance (WCAG)
- Performance optimizations
- Vercel-optimized for deployment
