# V0.app Component Generation Command

## Usage
Type `/v0-generate [component-type] [description]` in Cursor's Agent input

## Description
**V0.app FIRST**: Primary command for all component generation using Vercel's native V0.app integration.

## Features
- Generates React components using V0.app API
- Creates TypeScript interfaces automatically
- Implements Tailwind CSS styling
- Includes accessibility features
- Optimizes for Core Web Vitals
- Real estate specific components
- Property listings and cards
- Market analysis components
- Contact forms and lead capture
- Hero sections and layouts
- SEO-optimized content

## Examples
```
/v0-generate property-card luxury home with pool and mountain views
/v0-generate contact-form lead capture with market report
/v0-generate hero-section Summerlin West luxury homes
/v0-generate market-stats current pricing and trends
/v0-generate property-gallery image carousel with thumbnails
```

## Integration
- Uses `/api/v0/generate-component` endpoint
- Leverages Vercel's native V0.app API
- Optimized for Next.js 15+ and React 19+
- Integrates with existing RealScout and SEO infrastructure
